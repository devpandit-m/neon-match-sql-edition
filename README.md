# 🚀 NEON MATCH | Full-Stack SQL Edition

A futuristic, cyberpunk-themed **Memory Match game** built with a complete Full-Stack architecture. This project features a dynamic gameplay experience with a persistent global leaderboard.

---

## 🎨 Project Overview
This is a 4x4 grid memory game where players match pairs of space-themed icons. The game tracks the score and time, saving the results into a local database to show a live leaderboard.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Neon Glow UI), Vanilla JavaScript (ES6+)
- **Backend:** Python 3.x, Flask Framework
- **Database:** SQLite (Lightweight & Portable - No XAMPP required!)
- **Communication:** REST API (JSON) with Flask-CORS

---

## 📁 File Structure
- `app.py`: The Python backend handling API routes and SQLite database.
- `index.html`: The main game structure and overlay.
- `style.css`: Modern Cyberpunk styling and animations.
- `script.js`: Game logic, timer, and fetch requests.
- `game.db`: (Auto-generated) SQLite database file.
